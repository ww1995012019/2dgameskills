## 根因与修复

原通用头部模板为过窄、过长的轮廓，提示词又要求头贴模板，第二版因此削窄后脑和发量。整体配准的横纵缩放比例约1.012，主要问题已经在生成美术中，不能归咎为组装把正常头挤扁。旧检查只验证模板覆盖、孔洞与挂接，没有识别头型相对参考的比例异常。

新开发工具 `dev/template_head_proportions.py` 改为身份参考驱动的头部检查。自动分割头必须保留完整身份图坐标，所占RGB逐像素与本阶段身份图相同；哈希锁定源图、掩码、实际已登记生图、派生图、处理代码和新头合同。并非重新生成一张合格掩码，或降低旧肢体覆盖标准。头的身份形状合同明确替换已被用户否决的通用窄轮廓，旧合同保留。

行宽剖面排除狭窄的挂接颈部后，比较头的宽高比；相对差超过15%阻断。该阈值是开发检查，尚未做两位真实人物的商业标定。本例旧头差46.55%，被新检查拒绝；第三版差1.00%。完整脸、五官身份和美术质量依然必须看图；同轮廓的错脸/空白脸无法由此识别，测试明确保留 expectedFailure，不冒充语义检测。

第三版使用已认可短发短衣参考中自动分割的头作为生图参考，补完整颈部。AI重画了头，不声称原像素保留。组装按参考头/身体比例等比缩放，按参考颈/头比例确定挂点，将多余挂接皮肤藏到衣领后；领口宽度不能放大整颗头。挂接仅复用 `seat_head` 的有限平移，连接不足则阻断。本例无需平移，颈连续97.62%，原95%标准不变。

默认占位头模板也改为有完整后脑的圆形结构，并明确提示保留人物参考比例；不能只凭占位模板通过就认定真实头合格。旧模板组装分支只用于既有实验与合成测试，真实头返修使用有源图的新合同。

父阶段三块导入快照及blocked状态不变，次数1/3/3；子阶段不能重画导入部件。本阶段现在实际7次：头3次（已用尽），远臂、远腿、髋、剑各1次。模板家族总14次，不是全会话总数。`generation_ledger.json` 保存实际提示词、原图、参考快照与哈希，旧失败没有删除。修前/修后其他七层哈希完全相同。
