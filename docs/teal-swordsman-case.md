## 制作与成本

- 用户先请求生成身份立绘，随后请求根据该图制作动画。立绘并非完整分层素材，手臂遮挡身体。
- 以该立绘为身份参考，一次生成八部件图集，补齐不可见的肩/髋和衣服。脸、服装、纹样和配色
  作为设计参考；这是重制的分层美术，不是逐像素切出原立绘。
- `dev/atlas_rig.py` 通过连通区域分出八个部件，推断裸手、臂/腿骨段，再按统一成人比例组装。
  没有为本例手画掩码、手设关节或添加角色名字特判。空间顺序和语义归属仍需看图复核，不能
  把这个开发适配器当作任意图集均能自动理解的生产接口。
- 调用正式 known-joint binder。所有后续接缝/层级修复和动作重出使用同一组图层，未追加生图。
  全例生图计数：身份图 1、八部件图集 1、修复图 0；不是 8 次分部件生图。

## 真实问题及修复

最初数值 QA 已通过，但视觉放大图发现模型画了带开放切口的躯干脖子，覆盖在头部前面。
只平移头部无法修复材质归属；把唯一躯干的脖子删掉又会露洞。相关版本全部保留，未交付。

最终保留原躯干在头后提供完整皮肤/衣服；增加同几何、同 UV 的衣领前景副本，自动按顶端连接的
皮肤区域推断前景 alpha。前景不含冗余裸脖子，衣领仍在头前。半透明抗锯齿切边也必须清掉，
否则会留下点状旧切口。算法只改变前景副本 alpha，不画新 RGB，不改变原部件，也不放宽 QA。

`case-review-history.json`、各版静态/颈部放大图和旧 render/QA 都留在外部案例目录。
最终前景记录在 `rig-v7/collar_overlay.json`，推导资产哈希在该 rig 的 provenance 中。
