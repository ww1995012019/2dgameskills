Stand → reverse settle → accelerate → walk → decelerate → settle. Settle banks are used when present in this export. Stop is phase-aware and can take up to about one stride longer than the minimum braking time. Commands during a ramp are queued; the latest command wins. This uses a contact-locked standing stance rather than switching to the separate idle animation.

Use the buttons or hold the right arrow. The camera follows the character; ground marks show world travel. Baked images retain frame-sampling error. This is a canvas runtime demonstration, not validation of other engine controllers.
